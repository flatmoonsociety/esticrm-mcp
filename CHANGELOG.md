# Historia zmian

W tym pliku dokumentowane są wszystkie istotne zmiany projektu. Format jest oparty na [Keep a Changelog](https://keepachangelog.com/pl/1.1.0/), a numery wersji są zgodne z [wersjonowaniem semantycznym](https://semver.org/lang/pl/).

## Polityka wersjonowania

- wersja główna oznacza zmianę niezgodną wstecz w narzędziach MCP lub konfiguracji
- wersja poboczna dodaje zgodne wstecz narzędzia albo możliwości
- wersja poprawkowa obejmuje zgodne wstecz poprawki i drobne usprawnienia
